# QOR: этап 1 — стабилизация MVP

## Выявлено в исходном проекте

- Раздел каталога вызывал поиск по одной букве, но API отклонял запросы короче двух символов; результат ошибочно отображался как пустой каталог.
- Выбранный язык материала не отправлялся и не учитывался; параметр `language` использовался для языка шаблонного ответа. Год проверялся по частичному совпадению.
- Русская кнопка после переключения на казахский не возвращала язык ответа; мобильная навигация скрывалась.
- CSV-импорт пропускал записи без названия без объяснения; неверная кодировка не давала понятного сообщения. Экспорт использовал один файл на сервере, что создавало риск конфликтов.
- `llm_enabled` показывал наличие ключа как подключённую LLM, хотя интеграции не было. Надпись «семантический поиск» не соответствовала реализации.
- При каждом запуске на пустой таблице заново добавлялись демонстрационные записи.

## Изменено

- `app/main.py`: API списка с пагинацией, фильтры, проверка года и Unicode-поиск в каталоге, проверка CSV до транзакции, выдача ошибок, экспорт в ответе, корректное закрытие соединений, корректный индикатор LLM и одноразовое заполнение новой таблицы.
- `app/static/app.js`: постраничный каталог, серверный фильтр, обработка ошибок, передача фильтра языка и восстановление переключения языка ответа.
- `app/static/index.html`, `app/static/style.css`: пагинация, мобильная навигация, правдивые подписи и предупреждение о безопасности.
- `tests/test_api.py`, `requirements-dev.txt`: автоматизированные тесты.
- `README.md`, `STAGE1_REPORT.md`: запуск, API, результаты и ограничения.

## Проверено

- Запуск сервера Uvicorn и API на локальной SQLite.
- Автотесты: каталог и пагинация, фильтры, валидация года, UTF-8/казахские символы, CSV, отмена импорта при ошибках, сохранение данных и отсутствие повторного заполнения пустой таблицы.
- Браузер Chromium: мобильная навигация, отображение 10 записей, поиск по казахскому тексту с учётом регистра, комбинированные фильтры и импорт CSV. Проводилось на демонстрационной и тестовой базах.
- Docker и Render не проверялись: Docker недоступен в среде разработки.

## Ограничения

Это первый этап, не завершение всего ТЗ. Настоящая выгрузка КАБИС не импортирована; её кодировка и значения полей требуют подтверждения. Отсутствуют LLM/RAG, семантический поиск, авторизация, защищённый администраторский интерфейс и полная локализация. Не разворачивать в публичной сети до устранения проблем безопасности. Приближённый поиск и экспорт не проверены на полном объёме каталога.
